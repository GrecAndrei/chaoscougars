# CHAOS RUN — LSIA to Paleto Bay

4-player co-op survival gauntlet for FiveM. The squad grids up at LSIA,
drives ~12km north to Paleto Bay, and the server throws two things at them
the whole way: a 500+ effect chaos system and a Director spawning 16 types
of hostile cougars. Downed players bleed out unless a teammate revives them.
Reach the beacon at Paleto or die as a pack.

## Resources

| folder | purpose | prod? |
|---|---|---|
| `resource/` | the game mode (`fivemchaos`) | yes |
| `resource_repl/` | HTTP Lua REPL bridge for development | **never** |
| `resource_test/` | console-command test harness | no |

## Setup

```cfg
# server.cfg
ensure fivemchaos

# admin panel (F5), admin net events
add_ace group.admin chaoscougar.admin allow

# dev only — REPL bridge + force-effect
# ensure resource_repl
# set chaoscougar_dev_token "long-random-string"   # HTTP auth for /exec etc.
# setr chaoscougar_repl_enabled 1                  # client-side exec kill switch
add_ace group.admin chaoscougar.dev allow
```

No ACEs are needed to play. Players ready up with **E** in the lobby; the
run launches itself when everyone is in. `cc_start` from the server console
still force-starts.

## The systems (why this isn't just RNG)

- **Heat director** (`server/heat.lua`) — one intensity score fed by effect
  dispatches, cougar spawns, and downs. High heat = chaos picks only mild
  effects and the Director holds spawns (relief); low heat = spicier effects
  and faster spawn cadence (pressure). A player going down opens a 10s
  grace window so the rescue is playable.
- **Acts** — 25% / 50% / 75% progress announce OUT OF THE CITY, ALPHA
  TERRITORY (guaranteed first howler), THE FINAL CLIMB (guaranteed alpha).
- **Vote-the-chaos** (`Config.VoteEffects`) — with 2+ players, the chaos
  timer presents 3 candidate effects; squad votes with **1/2/3**; majority
  ships. The best argument generator in the mode.
- **Bleed-out & spectate** — downed players get a visible countdown
  (everyone sees the rescue clock); unrescued players spectate the pack.
- **Pride bonus** — driving within 40m of teammates pulses small heal/engine
  repair and shows the PRIDE chip. Formation driving is the meta.
- **Effect tuning** (`shared/effects_tuning.lua`) — flag corrections,
  severity tags (mild/medium/spicy) for the heat director, crowd tags for
  the empty northern stretches, and the ban list of run-ruining effects
  (progress-erasing teleports, instant suicide). Banned effects stay
  admin-dispatchable; they just never roll randomly. **Edit this file, not
  the generated registry** — the registry is regenerated by
  `tools/transpile_effects.py`.
- **Records** (`records.json`) — all-time best, per-day best, last runs,
  W/L. Lobby shows the card; beating the record announces itself.

## Console commands (server)

`cc_start` `cc_stop` `cc_status` `cc_difficulty` `cc_heat` `cc_records`
`cc_effect <id>` `cc_effects` `cc_active` `cc_director` `cc_spawn <type>`

## Player controls

| key | action |
|---|---|
| E | ready up (lobby) / hold to revive a teammate |
| 1 / 2 / 3 | vote on the next chaos effect |
| F9 | vote to pause |
| F5 | admin panel (needs `chaoscougar.admin`) |

## Cross-resource API

`fivemchaos` exports (server): `GetState`, `GetActiveEffects`,
`GetDirectorSnapshot`, `GetEffectById`, `DispatchEffectById(id[, duration])`.
The REPL exposes these inside `/exec` as `cc.state()`, `cc.effects()`,
`cc.director()`, `cc.effect(id)`, `cc.dispatch(id)`.

You are converting FiveM GTA5 Lua chaos effects from single-player to 4-player multiplayer.

## SYNC MODES
Every effect MUST be classified into exactly one sync_mode:
- LOCAL: Only affects the triggering player's own ped/vehicle. Uses PlayerPedId(), PlayerId(), or the vehicle they're currently in.
- GLOBAL_OWNED: Iterates world entity pools but ONLY modifies entities the local client owns. MUST use OwnershipGuard helpers.
- VISUAL: Client-only visual/audio effects (timecycles, weather, camera, HUD). Safe to run on all clients unchanged.
- SPAWN_SINGLE: Creates new entities (peds, vehicles). Only ONE client runs this. Must use GetNearestPlayerPed for targeting.
- META: Modifies server game state (timer speed, effect count). Calls TriggerServerEvent('cc:meta_set_internal', key, value).

## RULES
1. NEVER iterate GetGamePool('CVehicle'/'CPed'/'CObject') without using OwnershipGuard helpers in GLOBAL_OWNED effects.
2. NEVER call TaskCombatPed(ped, PlayerPedId(), ...) in SPAWN_SINGLE effects. Use GetNearestPlayerPed(GetEntityCoords(ped)) instead.
3. For LOCAL effects that only affect the player's own vehicle: GetVehiclePedIsIn(PlayerPedId(), false) is fine without ownership guard.
4. For GLOBAL_OWNED effects: replace ALL pool iteration patterns with OwnershipGuard.ForEachOwnedVehicle/Ped/Object(fn).
5. SetTimeScale, SetGravityLevel, timecycle modifiers, weather are all LOCAL to each client (safe without guard).
6. Effects receive (alive, seed) for timed, or (seed) for instant. alive() returns bool.
7. Spawned hostile peds need RetargetSpawnedPed(ped, intervalMs) call for multiplayer retargeting.
8. AddExplosion is LOCAL (each client sees their own), so meteor/airstrike effects are VISUAL.

## HELPERS AVAILABLE (already defined, just call them)
```lua
OwnershipGuard.IsOwner(entity) -- returns true if this client owns the entity
OwnershipGuard.ForEachOwnedVehicle(fn) -- iterates vehicles this client owns
OwnershipGuard.ForEachOwnedPed(fn) -- iterates non-player peds this client owns
OwnershipGuard.ForEachOwnedObject(fn) -- iterates objects this client owns
GetNearestPlayerPed(pos) -- returns closest living player ped to position
GetAllPlayerPeds() -- returns table of all living player peds
RetargetSpawnedPed(ped, intervalMs) -- starts retargeting loop for hostile spawns
```

## OUTPUT FORMAT
For each effect, output:
1. A comment: `-- sync_mode: MODE`
2. The function definition with multiplayer-safe code
3. Keep the same function name (FX_*) and signature pattern

Output ONLY the Lua code. No explanations, no markdown fences. Just raw Lua ready to concatenate into a file.

## CLASSIFICATION GUIDE
- Player movement/state/weapon/health/wanted → LOCAL
- Player's own vehicle power/grip/speed → LOCAL
- All vehicles in world (force, flip, explode, color) → GLOBAL_OWNED
- All peds in world (task, weapon, ragdoll) → GLOBAL_OWNED
- All objects in world (force, physics) → GLOBAL_OWNED
- Timecycle, weather, camera, night vision, HUD → VISUAL
- Spawn peds (hostile NPCs, clowns, etc.) → SPAWN_SINGLE
- Spawn vehicles → SPAWN_SINGLE
- Timer/duration/chaos modifiers → META
- Teleport player → LOCAL
- Explosions around player → VISUAL (AddExplosion is per-client)
